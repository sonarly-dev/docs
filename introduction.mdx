Sonarly is an AI-powered platform that transforms noisy production alerts into clear, actionable bug reports with automatic PR fixes.

Connect your existing tools — Sentry, Datadog, Grafana, GCP, and more — and Sonarly's AI engineer will triage every alert, find the root cause in your code, and open a pull request with the fix.

## How it works

<Steps>
  <Step title="Connect your tools">
    Link your error tracking (Sentry), observability (Datadog, Grafana, GCP, SigNoz, AWS, Vercel, Mezmo), and notification (Slack, Discord) platforms. Takes 2 minutes, no SDK or code changes.
  </Step>
  <Step title="Connect your codebase">
    Install the Sonarly GitHub App or connect GitLab so the AI can access your repositories and create pull requests.
  </Step>
  <Step title="AI triages every alert">
    Each incoming alert is automatically analyzed: severity classification, root cause identification, git blame, and deduplication against known issues.
  </Step>
  <Step title="Get a PR with the fix">
    For each new issue, Sonarly opens a pull request with the fix, a detailed root cause explanation, and the commit that introduced the bug. Review, merge, and move on.
  </Step>
</Steps>

## Key capabilities

- **Automatic triage** — Every alert is classified as critical, medium, or low based on user impact
- **Root cause analysis** — AI explores your codebase to find exactly what went wrong and who introduced it
- **Smart deduplication** — Similar alerts are grouped automatically, reducing noise by up to 80%
- **PR generation** — Pull requests with fixes, root cause explanation, and git blame
- **Observability queries** — AI queries your logs, metrics, and traces (Datadog, Grafana, GCP, SigNoz, AWS, Vercel, Mezmo) during investigation
- **Slack notifications** — Rich notifications with severity, root cause, and action buttons
- **Live streaming** — Watch the AI think and work in real-time from your dashboard
