Sonarly sends rich Slack notifications when new bugs are found, incidents are investigated, and pull requests are created.

## Connect Slack

<Steps>
  <Step title="Authorize">
    Go to **Settings** → **Slack** and click **Connect Slack**. Authorize the Sonarly bot in your workspace.
  </Step>
  <Step title="Select a channel">
    Choose which Slack channel receives notifications.
  </Step>
  <Step title="Configure preferences">
    Set severity preferences — for example, only get notified for critical and medium issues.
  </Step>
</Steps>

## Notification format

Sonarly sends rich Block Kit messages with:

- **Severity badge** — Visual indicator (critical, medium, low)
- **Issue title** — Clear, AI-generated summary
- **Root cause** — What went wrong
- **Fix summary** — What the PR does
- **Action buttons** — View in Sonarly, view PR on GitHub/GitLab

## Slack bot agent

You can also **@mention the Sonarly bot** in any Slack channel to ask it questions. The bot launches Claude Code with your conversation context and responds directly in the thread.

The bot:
- Reads up to 10 recent messages in the thread for context
- Runs Claude Code with access to your codebase and observability tools
- Streams live progress updates in the Slack thread
- Returns findings directly in the conversation

## Permissions

| Scope | Purpose |
|-------|---------|
| `chat:write` | Send notifications and bot responses to channels |
| `channels:read` | List public channels for selection |
| `groups:read` | List private channels for selection |
| `channels:history` | Read channel messages for bot context (when @mentioned) |
| `groups:history` | Read private channel messages for bot context |
| `channels:join` | Join channels to post notifications |
| `users:read` | List workspace members (for git blame → Slack user mapping) |
| `users:read.email` | Match Slack users to git commit authors by email |

<Info>
The bot receives @mention events via the Slack Events API (webhook subscription configured during setup), which does not require an additional OAuth scope.
</Info>
