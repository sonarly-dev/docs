Sonarly connects to AWS CloudWatch to query your logs during incident investigation. The AI agent can search, sample, and analyze log groups to find root causes.

## Connect CloudWatch

<Tabs>
  <Tab title="IAM Role (recommended)">
    <Steps>
      <Step title="Create an IAM Role">
        Create a cross-account IAM Role in your AWS account with the read-only policy below. Add Sonarly's AWS account as a trusted entity with an External ID (provided during setup).
      </Step>
      <Step title="Enter Role ARN">
        On the Sonarly settings page, enter the Role ARN and your AWS region. Sonarly uses `sts:AssumeRole` with the External ID to get temporary credentials.
      </Step>
      <Step title="Validation">
        Sonarly validates access by listing your log groups.
      </Step>
    </Steps>
  </Tab>
  <Tab title="Static credentials (legacy)">
    <Steps>
      <Step title="Create IAM credentials">
        Create an IAM user with the read-only policy below. Generate an Access Key and Secret Key.
      </Step>
      <Step title="Enter credentials">
        On the Sonarly settings page, enter your AWS Access Key, Secret Key, and region.
      </Step>
      <Step title="Validation">
        Sonarly validates access by listing your log groups.
      </Step>
    </Steps>
  </Tab>
</Tabs>

## Observability tools available to the AI

| Tool | What it does |
|------|-------------|
| **List log groups** | Discover available CloudWatch log groups |
| **Log statistics** | Get volume and field statistics for a log group |
| **Sample logs** | Fetch recent log entries from a group |
| **Search logs** | Filter logs by pattern, timeframe, and fields |
| **Logs around time** | Get logs in a window around a specific timestamp |

<Info>
Your AWS credentials never leave the Sonarly backend. All CloudWatch queries go through a server-side proxy.
</Info>

## IAM policy example

```json
{
  "Version": "2012-10-17",
  "Statement": [
    {
      "Effect": "Allow",
      "Action": [
        "logs:DescribeLogGroups",
        "logs:GetLogEvents",
        "logs:FilterLogEvents",
        "logs:GetLogGroupFields"
      ],
      "Resource": "*"
    }
  ]
}
```
