Sonarly receives Opsgenie alert webhooks and automatically investigates them with AI.

## Setup

<Steps>
  <Step title="Get your webhook URL">
    In Sonarly, go to **Settings**. Copy your Opsgenie webhook URL:
    ```
    https://sonarly.dev/api/webhooks/opsgenie?tenant_id=YOUR_TENANT_ID
    ```
  </Step>
  <Step title="Add webhook in Opsgenie">
    In Opsgenie, go to **Settings** → **Integrations** → **Add integration** → **Webhook**. Paste the Sonarly URL. Include the GenieKey API key for authentication.
  </Step>
</Steps>

## How it works

1. Opsgenie sends an alert webhook to Sonarly
2. GenieKey API key is verified
3. Sonarly deduplicates against recent alerts (5-minute window)
4. Claude Code investigates: queries your logs, analyzes your codebase
5. An incident report with root cause and fix is generated
6. You're notified via Slack

## Webhook security

Sonarly authenticates Opsgenie webhooks using the GenieKey API key included in the request.
