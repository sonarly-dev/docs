Sonarly receives Incident.io alert webhooks and automatically investigates them with AI.

## Setup

<Steps>
  <Step title="Get your webhook URL">
    In Sonarly, go to **Settings**. Copy your Incident.io webhook URL:
    ```
    https://sonarly.dev/api/webhooks/incidentio?tenant_id=YOUR_TENANT_ID
    ```
  </Step>
  <Step title="Add webhook in Incident.io">
    In Incident.io, go to **Settings** → **Webhooks** → **Add endpoint**. Paste the Sonarly URL and select alert events.
  </Step>
</Steps>

## How it works

1. Incident.io sends an alert webhook to Sonarly
2. Signature is verified using Standard Webhooks v1
3. Sonarly deduplicates against recent incidents (5-minute window)
4. Claude Code investigates: queries your logs, analyzes your codebase
5. An incident report with root cause and fix is generated
6. You're notified via Slack

## Webhook security

Sonarly verifies Incident.io webhooks using the Standard Webhooks v1 signature format with constant-time comparison.
