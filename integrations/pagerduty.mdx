Sonarly receives PagerDuty incident webhooks and automatically investigates them — querying your observability tools, analyzing your codebase, and generating a root cause report with a fix.

## Setup

<Steps>
  <Step title="Get your webhook URL">
    In Sonarly, go to **Settings**. Copy your PagerDuty webhook URL:
    ```
    https://sonarly.dev/api/webhooks/pagerduty?tenant_id=YOUR_TENANT_ID
    ```
  </Step>
  <Step title="Add webhook in PagerDuty">
    In PagerDuty, go to **Integrations** → **Generic Webhooks (v3)** → **New Webhook**. Paste the Sonarly URL and select the events you want to forward (e.g. `incident.triggered`).
  </Step>
  <Step title="Add HMAC secret (recommended)">
    Set a shared secret in PagerDuty for webhook signature verification. Sonarly will verify the `X-PagerDuty-Signature` header on every incoming webhook. Contact support to configure the shared secret on the Sonarly side.
  </Step>
</Steps>

## How it works

1. PagerDuty sends an incident webhook to Sonarly
2. HMAC-SHA256 signature is verified
3. Sonarly deduplicates against recent incidents (5-minute window)
4. Claude Code investigates: queries logs from your connected observability tools, analyzes your codebase
5. An incident report is generated with timeline, root cause, and suggested fix
6. If a code fix is identified, a PR is created
7. You're notified via Slack with the full summary

## Webhook security

Sonarly verifies PagerDuty webhooks using the `X-PagerDuty-Signature` header with constant-time HMAC-SHA256 comparison.
