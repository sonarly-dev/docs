---

<AccordionGroup>
  <Accordion title="How long does setup take?">
    About 2 minutes. Sign up, connect your alert sources (Sentry, Datadog, Grafana, GCP, etc.) and the AI starts triaging immediately. No SDK, no code changes.
  </Accordion>

  <Accordion title="Does Sonarly replace my existing tools?">
    No. Sonarly sits on top of your existing stack. Your tools collect alerts — Sonarly triages them, finds root causes in your code, and opens a PR with the fix.
  </Accordion>

  <Accordion title="How long does AI analysis take?">
    Initial triage (severity, title, description) takes seconds. Deep code analysis with root cause and PR generation takes 2-5 minutes per issue.
  </Accordion>

  <Accordion title="Will Sonarly auto-merge PRs?">
    Never. PRs are created for your review. You control when and whether to merge.
  </Accordion>

  <Accordion title="Will Sonarly modify my Sentry/Datadog data?">
    No. Sonarly only requests read permissions from your tools. We never resolve issues, change assignments, or update anything in your connected platforms.
  </Accordion>

  <Accordion title="How does deduplication work?">
    Multiple tiers: exact ID matching, error message fingerprinting, and AI semantic comparison. After code analysis, a second pass catches errors with different messages but the same root cause. This typically reduces alert noise by up to 80%.
  </Accordion>

  <Accordion title="Is my code secure?">
    Yes. SOC 2 Type 2 certified. Code runs in isolated sandboxes with 24h TTL. API keys never leave the backend. We never store your source code permanently. See [Security](/security) for details.
  </Accordion>

  <Accordion title="Do you support self-hosted GitLab?">
    Yes. Enter your GitLab instance URL during setup and Sonarly will connect to your self-hosted instance.
  </Accordion>

  <Accordion title="Can I use multiple alert sources at the same time?">
    Yes. Connect Sentry, Datadog, Grafana, GCP, SigNoz, and any other supported tool simultaneously. All alerts flow into the same unified Issues page.
  </Accordion>

  <Accordion title="What AI models does Sonarly use?">
    Gemini for fast triage and deduplication. Claude Code (Anthropic) for deep codebase analysis, root cause identification, and fix generation.
  </Accordion>

  <Accordion title="How can I contact support?">
    Email us at [founders@sonarly.dev](mailto:founders@sonarly.dev) or join our [Discord](https://discord.gg/9XDVzde4G4).
  </Accordion>
</AccordionGroup>
